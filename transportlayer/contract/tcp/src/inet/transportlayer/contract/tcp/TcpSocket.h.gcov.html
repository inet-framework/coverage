      28                 :             :  * TcpSocket is a convenience class, to make it easier to manage TCP connections
      29                 :             :  * from your application models. You'd have one (or more) TcpSocket object(s)
      30                 :             :  * in your application simple module class, and call its member functions
      31                 :             :  * (bind(), listen(), connect(), etc.) to open, close or abort a TCP connection.
      32                 :             :  *
      33                 :             :  * TcpSocket chooses and remembers the connId for you, assembles and sends command
      34                 :             :  * packets (such as OPEN_ACTIVE, OPEN_PASSIVE, CLOSE, ABORT, etc.) to TCP,

      50                 :             :  * </pre>
      51                 :             :  *
      52                 :             :  * Dealing with packets and notification messages coming from TCP is somewhat
      53                 :             :  * more cumbersome. Basically you have two choices: you either process those
      54                 :             :  * messages yourself, or let TcpSocket do part of the job. For the latter, you
