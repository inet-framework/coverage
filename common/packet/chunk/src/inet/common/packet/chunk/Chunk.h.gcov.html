      77                 :             :  *    is one exception to this rule, when the chunk is exclusively owned. That
      78                 :             :  *    is when it has exactly one reference. Immutable chunks cannot be changed

      81                 :             :  *    Incomplete chunks are not totally filled in. For example, when a chunk is
      82                 :             :  *    created by deserializing it from insufficient amount of data.

      85                 :             :  *    through a lossy channel causing bit errors in it.
      86                 :             :  *  - properly represented, then may become improperly represented, but never
      87                 :             :  *    the other way around. Improperly represented chunks misrepresent their
